| D-05 | (user) Demand(o,i) = Σ linked BOM qty × panel qty of open order o; issued(o,i) = issues − workshop returns; shortage = max(0, demand − issued − reserved). | D-06 | (user) Weighted average, value-based (clarified by R-11): `avg = value / on_hand` (4 dp half-up, display and issue cost); a movement's `value` is whole VND half-up. Receipt at PO unit price excl. VAT: `+round(q × price)`. Issue at current avg: `−round(q × avg)`, but an issue that brings `on_hand` to 0 takes the whole remaining value. Workshop return at the order's net issued average for the item `(Σ issue values − Σ return values)/(net issued qty)`: `+round(q × that cost)`. Supplier return (user 2026-10-27): every return movement stores `reference_value = round(q × PO line unit price)` (for P5 supplier-payable reconciliation); a return that brings `on_hand` to 0 takes the whole remaining value (movement value = −value, like the last issue); otherwise `value' = max(0, value − reference_value)` and movement value = `value' − value` (the real change, also when clamped). Count adjustment at current avg; when `on_hand = 0` the last movement's `avg_cost_after`, else the item's `reference_price`, else 0 (opening balance) | FIFO, standard cost | user rule; P6 reads ledger values | `value = Σ movement values` | worked examples in tasks 05, 12, 13, 14 are the oracle |
